# AI Prompt History

This document provides a summary of the main types of prompts I used while developing PerformTrack.

The examples below are paraphrased summaries, not verbatim chat transcripts.

## ChatGPT

1. Help me understand the requirements and plan the structure of an employee performance management system.
2. Help me understand and troubleshoot FastAPI backend and PostgreSQL integration issues.
3. Help me debug frontend and backend API integration.
4. Explain how to validate goal progress and maintain consistency between related records.
5. Help me understand test failures and verify the application.

## GitHub Copilot

1. Suggest implementation approaches for Next.js components and TypeScript code.
2. Help with code completion and debugging during frontend development.
3. Suggest improvements while working with backend routes and application logic.

## How I Used the Suggestions

I reviewed suggestions, adapted them to the project requirements, and tested the resulting implementation. I used AI assistance to understand problems and improve development efficiency rather than treating generated code as automatically correct.
